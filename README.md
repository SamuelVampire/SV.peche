# Pêche 🍑

### [🍑 打开 Pêche / Open Pêche](https://samuelvampire.github.io/SV.peche/)


Pêche 是一个基于《Inspire 1 – A1》学习内容制作的法语单词学习网页。

这个项目最初是为了配合个人法语 A1 学习使用，把 Inspire 1 中整理出的词汇集中到一个简单、轻量的网页里，通过选择、回忆和间隔复习来练习法语词汇。

目前词库覆盖 Unit 1–8，共整理约 552 条词汇及表达。

> Pêche 是个人学习项目，并非《Inspire 1》的官方配套产品，与教材作者、出版社及相关权利方无隶属或合作关系。

## 使用方式

Pêche 可以直接通过浏览器使用，不需要注册账号，也不需要登录。

### 💻 电脑端

打开网页后可以直接使用鼠标操作，也可以使用键盘快捷键。

首页：

- `L` — Learn，学习新词
- `R` — Review，复习到期词汇

学习过程中：

- `1` / `2` / `3` / `4` — 选择对应答案
- `Q` — 认识
- `E` — 不认识 / 忘记
- `W` — 模糊（Review 模式）
- `Tab` — 重新播放当前法语单词
- `Space` — 显示答案后进入下一个单词

因此在电脑上基本可以不使用鼠标完成整个学习过程。

---

## 📱 手机 / iPad

Pêche 也可以直接通过手机或平板浏览器使用。

页面针对较小屏幕进行了基础适配，学习按钮可以直接触摸操作，因此不需要外接键盘。

如果希望像普通 App 一样使用，可以把网页添加到主屏幕。

### iPhone / iPad

使用 Safari 打开 Pêche：

**分享 → 添加到主屏幕**

之后就可以从桌面直接打开。

### Android

使用 Chrome 打开 Pêche，可以通过浏览器菜单中的：

**添加到主屏幕**

将网页添加到桌面。

> 当前 Pêche 本质上仍然是一个 Web App。添加到主屏幕后可以获得更接近独立 App 的使用体验，但部分行为仍然取决于浏览器和系统。

## 🍑 Learn 模式

每轮 Learn 最多随机抽取 20 个尚未完成学习的新词。

学习分为两个阶段。

### 1. Multiple Choice

看到法语单词后，从四个中文释义中选择正确答案。

连续掌握后，该词会进入主动回忆阶段。

### 2. Recall

看到法语单词后，由自己判断：

- Q — 认识
- E — 不认识

达到学习条件后，这个单词会完成本轮学习，并进入之后的 Review。

---

## 🔁 Review 模式

已经学习过的单词会根据复习记录再次出现。

复习时可以选择：

- `Q` — 认识
- `W` — 模糊
- `E` — 忘记

不同选择会影响这个单词下一次出现的时间。

Pêche 使用一个比较轻量的间隔复习逻辑，而不是完整复刻 Anki、FSRS 或其他专业记忆算法。

它的目标很简单：

**让我真的把这些法语词记住，而不是让我管理一个复杂的背词软件。**

---

## 🔊 法语发音

Pêche 会调用浏览器 / 操作系统提供的语音合成功能（Speech Synthesis）播放法语单词。

默认语言设置为：

`fr-FR`

因此：

- 不需要额外下载音频文件；
- 不需要单独的语音 API；
- 不同设备、浏览器和操作系统的声音可能不同；
- 发音质量取决于设备中可用的法语语音；
- 某些浏览器可能需要用户先与页面交互，才允许播放声音。

网页中的发音仅作为词汇学习辅助，不应视为专业语音或标准发音课程的替代品。

---

## 💾 学习进度

Pêche 当前使用浏览器的 `localStorage` 保存学习记录。

这意味着数据主要保存在你正在使用的浏览器和设备中。

请注意：

- 不需要账号；
- 数据不会自动在电脑、手机、iPad 之间同步；
- 换设备后不会自动出现原设备的学习记录；
- 清除浏览器网站数据、缓存或本地存储可能导致学习记录丢失；
- 无痕 / 隐私浏览模式不适合长期保存学习进度。

因此，如果你在 iPad 上长期学习，建议尽量固定使用同一个浏览器和同一个网页入口。

## ⚠️ 当前版本注意事项

Pêche 是一个个人学习项目，目前仍然比较简单。

可能存在：

- 个别词汇释义需要进一步校对；
- 教材词汇整理存在遗漏或重复的可能；
- 浏览器之间的语音效果不同；
- 学习记录目前无法跨设备同步；
- 清除浏览器数据可能导致学习记录丢失；
- 网页更新后，部分浏览器可能需要刷新才能加载最新版本；
- 不同移动设备上的“添加到主屏幕”体验可能存在差异。

词库目前按照个人学习需求整理，不应被视为教材官方词汇表。
