# Pêche 🍑

### [🍑 打开 Pêche / Open Pêche](https://samuelvampire.github.io/SV.peche/)

Pêche 是一个个人法语词汇学习网页。目前包含《Inspire 1 – A1》课程词库，以及正在持续扩充的 TCF / CEFR 词汇库。

这个项目最初是为了配合个人法语 A1 学习使用，把 Inspire 1 中整理出的词汇集中到一个简单、轻量的网页里，通过选择、回忆和间隔复习来练习法语词汇。

Inspire 词库目前覆盖 **Unit 1–8**，共整理 **579 条词汇及表达**，按照教材的 Unit 与 Leçon 整理为 **18 个学习组**。TCF / TEF 词库现已完整导入一份经出版社人工筛选的 **5,452 条考试词汇来源表**，并保留此前 Pêche 中未被这份来源表覆盖的学习词条，因此当前学习库共 **5965 条**。所有词条都被组织为 **A1 / A2 / B1 / B2 / C1 → 主题 → 每组最多 25 条**。

> Pêche 是个人学习项目，并非《Inspire 1》的官方配套产品，与教材作者、出版社及相关权利方无隶属或合作关系。

## 使用方式

Pêche 可以直接通过浏览器使用，不需要注册账号，也不需要登录。

首页提供两种单词出现顺序，并提供 Learn / Review / Spelling 三个并列入口：

- **全部随机** — 保持原始学习方式，从所有符合条件的单词中随机出现；
- **按课程** — 按 Inspire 的 Unit / Leçon 顺序选择学习组，进入组后单词随机出现。

### 💻 电脑端

首页：

- `L` — Learn，学习新词
- `R` — Review，复习到期词汇
- `S` — Spelling，从已经完成 Learn、进入复习状态的词中进行听音拼写

学习过程中：

- `1` / `2` / `3` / `4` — 选择对应答案
- `Q` — 认识
- `E` — 不认识 / 忘记
- `W` — 模糊（Review 模式）
- `Tab` — 重新播放当前法语单词
- `Space` — 显示答案后进入下一个单词

因此在电脑上基本可以不使用鼠标完成整个学习过程。

## 🍑 Learn 模式

### 全部随机

保持最初的 Pêche 学习逻辑。新词采用 **12 词滚动学习窗口**。当前窗口中的词按轮转顺序再次出现；词完成学习后，从后续新词中补入窗口，直到本轮词汇完成。12 词窗口用于拉开同一个词再次出现的间隔，减少 7 词窗口下进入 Recall 后反复看到同一小批词的感觉，同时仍保留足够的早期重复。学习页左上角的进度分母从 session 开始就固定显示本轮总词数，不会随着滚动窗口补词从 7、14 一路增长。

### 按课程

词库按照 Inspire 1 的 Unit 与 Leçon 整理为 **18 个学习组**。

课程组按照教材顺序排列；进入某一组后，同样使用 12 词滚动学习窗口。每组会显示当前剩余的新词数量。

点击首页的“课程模式”会先进入课程词库选择页。目前 **Inspire 与 TCF 均可使用**，两套词库的学习记录彼此独立。

这种模式优先保留教材的课程结构，不强制把每组切成固定 20 个词，因此每组词量可能不同。

### Multiple Choice

看到法语单词后，从四个中文释义中选择正确答案。

如果选错，Pêche 会弹出该错误选项对应的：

- 法语单词；
- 中文释义；
- 自动法语发音；
- 手动重播发音按钮。

点击“确定”后关闭解释窗口并继续当前题目。

连续掌握后，该词进入主动回忆阶段。

### Recall

看到法语单词后，由自己判断：

- `Q` — 认识
- `E` — 不认识

达到学习条件后，该词完成本轮学习。**完成 Learn 约 12 小时后**，这个词会第一次进入到期 Review。

这个时间按单词所在学习组的实际完成时间计算，不是每天固定在凌晨刷新。例如一组在 20:00 完成，大约会在第二天 08:00 进入 Review。

学习页面同时显示当前词所属的 **Unit 与 Leçon**。

## 🔁 Review 模式

已经学习过的单词会根据各自的 `due` 时间再次进入待复习状态。Review 首页数字显示的是**当前所有已经到期的词数**，但不会把它们一次性全部塞进一个 session。

### 全部随机

如果一次积累了很多 overdue 词，Pêche 会：

1. 找出当前所有 `due <= 现在` 的词；
2. 按 **最早到期优先** 排序；
3. 每次只取最前面的最多 **25 个词**；
4. 在这 25 个内部随机出现；
5. 当前 session 固定后，练习过程中后来新到期的词不会临时插进来；
6. 当前 25 个处理完后，下一次进入 Review 再取下一批。

因此即使积累了几百个待复习词，首页仍会显示真实 backlog 数量，但单次 Review 不会变成几百词的大 session。

### 按课程

课程模式仍然允许按课程组选择 Review。进入一个组时，只取该组中已经到期的词，并同样限制为**最多 25 个**；若同一组还有更多 overdue 词，完成这一轮后可继续进入该组处理下一批。

### 中途退出与 session 保存

Review 拥有独立的持久 session。做到一半返回主页时，当前 Review 状态会保存；之后即使先去 Learn 或 Spelling，也不会覆盖这轮 Review。再次进入 Review 时会优先恢复未完成 session。

这意味着：

- 当前批次不会因为第二天又有新词到期而膨胀；
- 新到期词只进入全局待复习集合，等待当前批次结束；
- 已经在本轮获得 1 次“认识”的词会保留这次确认状态。

### Review 判断

复习时可以选择：

- `Q` — 认识
- `W` — 模糊
- `E` — 忘记

“认识”仍然需要在当前 Review session 中达到 **2 次确认**，才算这一轮完成。完成后，下一次到期时间按照当前间隔约 **× 2.2** 拉长。\n\n如果按了“认识”以后，在答案页看到中文释义才发现自己其实记错了，可以点击 **记错了 E**（或直接按 `E`）。Pêche 会撤销刚才这次“认识”：恢复该词进入本题前的 Review 进度与 due / interval，不把这次误判算进去，并让它继续留在当前 session 里之后再次出现。

大致规律仍为：

**首次 Review（Learn 后约 12 小时） → 约 2 天 → 约 4 天 → 约 9 天 → 约 20 天 → 约 44 天 → 约 97 天……**

如果选择：

- **模糊** — 当前确认计数归零，重新安排一个较保守的后续间隔，并立刻退出当前 session；不会在本轮里马上又随机出现；
- **忘记** — 间隔重置，约 **10 分钟后**重新到期，并立刻退出当前 session；即使 10 分钟在本轮进行期间到了，也不会插回已经固定的当前批次，而是在下一次 Review session 中重新进入。

Pêche 使用轻量的间隔复习逻辑，而不是完整复刻 Anki、FSRS 或其他专业记忆算法。

它的目标仍然是：

**让我真的把这些法语词记住，而不是让我管理一个复杂的背词软件。**

## ✍️ Spelling 模式

Spelling 使用独立的**待拼池**。单词完成 Learn 后会进入待拼池；每个词在 Spelling 中连续拼对两次后，才会从待拼池移除。

每次新建 Spelling 只从待拼池取最多 **25 个词**作为当前 session。中途返回主页会保存这一轮的拼写进度；之后新学会的词只加入待拼池，不会插入正在进行的旧 session。旧 session 完成后，下次再从待拼池取下一批。这样不会因为历史已学词越来越多，就在每次打开 Spelling 时重新把全部词塞进来。

升级到待拼池机制之前已经学过的历史词不会一次性全部补进待拼池，避免突然制造巨大 backlog；升级后新完成 Learn 的词，以及升级时尚未完成的 Spelling session，会继续按新规则记录。

每题会自动播放法语发音：

- 输入听到的法语单词或表达后按 `Enter` 检查；
- 拼错时立即显示正确法语拼写，并停留在原题，必须重新完整拼对；
- 拼错不会因为最后改对而被抹掉；该词的连续正确次数会清零，并继续留在当前 session；
- 第一次拼对后回到队尾；之后再次连续拼对才算完成；
- 连续拼对两次后显示完成状态，并从待拼池移除；
- 完整拼对后显示中文释义并再次自动发音；
- `Tab` 随时重播当前发音；
- 答案页按 `Space` 进入下一题。

答题输入阶段的空格保留为正常输入，因此多词表达也可以进行拼写练习。

## 🇫🇷 TCF / CEFR 词库与数据来源

TCF 词库不是 France Éducation international 发布的“官方 TCF 必背词表”。当前核心来源是一份由出版社人工筛选的 TCF / TEF 考试词汇表，共 **5,452 条**；Pêche 将它完整纳入学习库，但这仍不等于考试机构规定的固定词汇边界。

当前词库由几层数据组成：

- **出版社筛选来源层（5,452 条）** — 原始 CSV 只提供法语单词、音标和中文释义；这些字段按来源保留。原文件**没有 CEFR 等级列，也没有主题列**，因此等级与主题不是出版社提供的数据；
- **Pêche 分级与主题层** — 每个词都必须落入一个学习主题，并按 CEFR → 主题 → 每组最多 25 条切组。与旧 Pêche / FLELex 数据能匹配的词优先保留已有等级；其余词的 CEFR 仅作为 Pêche 的学习顺序估计，不应当作出版社或 TCF 官方分级；

- **Pêche 手工整理层** — 根据日常生活、个人信息、家庭、住房、工作、教育、健康、交通、消费、环境、媒体、科技、社会议题、观点表达等常见学习主题整理词汇和表达；
- **FLELex / CEFRLex 层** — 用于辅助判断法语 lemma 的 CEFR 等级与频率。当前使用的 FLELex / Beacco 数据包含 A1–C2 分级信息；
- **中文学习释义层** — 能够匹配到已校对/已有学习释义的数据时，优先使用该释义；
- **GPT 暂译层** — 对仍缺少合适中文学习释义、但值得进入 B1/B2 学习库的高频词，由 GPT 根据常见法语词义编写简短中文学习解释，并在界面中明确标记来源；
- **固定表达 / multiword expressions** — B1/B2 尤其需要掌握的不只是单个 lemma，因此词库会逐步加入连接词、固定搭配、常用短语和多词表达，而不是只扩大孤立单词数量。

### GPT 暂译标记

如果某个词条当前使用模型生成的中文解释，答案旁会以浅色小字显示：

> **AI　当前暂无专业词典中文释义 · GPT 翻译，仅供学习参考**

这个标记表示：法语词本身及其 CEFR / 频率来源可以来自现有词汇数据，但**当前显示的中文解释不是专业法汉词典释义**。它的目标是先提供足够清楚、适合记忆的学习提示，而不是冒充权威词典定义。

后续如果取得并核对了更可靠、许可允许使用的专业词典释义，可以用经过核验的版本替换 GPT 暂译；来源标记也应随之更新或移除。

### 关于 CEFR 等级

词汇的 CEFR 等级应理解为**学习与语料分级参考**，而不是“这个词只会在某一级考试出现”。同一个词可能有多个词性、多个义项，不同语料库或教学资源也可能给出不同等级。Pêche 当前优先保留对学习最有用的分级，同时继续进行去重、词性检查和释义校对。

### 关于主题分类与学习组

TCF / TEF 词库现在要求**每个词都有主题**。当前采用 29 个学习主题，先按 CEFR 分层，再按主题排列；同一“等级 × 主题”超过 25 条时继续切成下一组。课程页面因此显示例如“B1 · 身体与健康 · 第 3 组”，而不是把不同主题混进一个按数量机械切分的组。

主题与 CEFR 都是 Pêche 的学习组织元数据。尤其对这次 5,452 条来源表，原 CSV 没有等级 / 主题字段；后续若人工审计发现归类不合适，可以修改 metadata，而不改变原始词形、释义或学习记录 ID。

### 数据许可与再利用

当前 CEFR / 频率整理会参考 **FLELex / CEFRLex**。FLELex 数据带有其自身的许可条件（包括 **CC BY-NC-SA 4.0** 的相关数据版本），因此 Pêche 目前继续按**个人、学习、研究、非商业用途**处理这些数据。

项目中的教材整理内容、第三方词汇数据、中文释义以及项目代码并不天然共享同一种授权。若未来计划商业化、重新打包数据集、公开提供词库下载或用于其他产品，应逐项重新检查原始来源、署名要求、ShareAlike / NonCommercial 条件以及教材版权，而不能仅依据本仓库 README 判断可以自由商用。

### 词库清洗原则

Pêche 不会因为文件很大就未经处理地直接塞进学习流程。对于这次已经由出版社人工筛选的 5,452 条考试词汇，采用“**完整保留来源词表 + Pêche 再做学习结构化**”的方式；进入正式学习库前执行：

1. lemma / 表达规范化与重复项检查；
2. CEFR 等级和频率参考；
3. 专有名词、异常字符串和明显低价值条目的过滤；
4. 词性与常见义项检查；
5. 中文学习释义匹配或 GPT 暂译标记；
6. 主题归类；
7. B1/B2 固定搭配、连接表达和 multiword expressions 的补充；
8. 在后续发现更可靠释义时覆盖临时版本，而不是把旧解释永久视为正确答案。

因此，**词库规模不是唯一目标**。Pêche 更优先保证进入学习流程的内容至少是可理解、可追踪来源、并且知道哪些部分仍需要继续核验。

## 🔊 法语发音

Pêche 调用浏览器 / 操作系统提供的语音合成功能（Speech Synthesis）播放法语单词。

默认语言：

`fr-FR`

因此：

- 不需要额外下载音频文件；
- 不需要单独的语音 API；
- 不同设备、浏览器和操作系统的声音可能不同；
- 发音质量取决于设备中可用的法语语音；
- 某些浏览器可能需要用户先与页面交互，才允许播放声音。

网页中的发音仅作为词汇学习辅助，不应视为专业语音或标准发音课程的替代品。

## 💾 学习进度

Pêche 当前使用浏览器的 `localStorage` 保存学习记录。

这意味着数据主要保存在当前浏览器和设备中：

- 不需要账号；
- 数据不会自动在电脑、手机、iPad 之间同步；
- 换设备后不会自动出现原设备的学习记录；
- 清除浏览器网站数据或本地存储可能导致学习记录丢失；
- 无痕 / 隐私浏览模式不适合长期保存学习进度。

更新词库与课程模式时，Pêche 继续兼容现有学习记录，不会仅因为切换“全部随机 / 按课程”而主动清空进度。
